## Features

- **Option Wheel Navigation** — A curved, draggable side-navigation inspired by React Bits, ported to vanilla JS. Supports scroll, drag, click, and keyboard input.
- **Scroll-Driven Animations** — Intersection Observer-based reveal system with staggered transitions.
- **Cursor Glow** — Subtle radial light that follows the pointer on desktop.
- **Project Card Tilt** — Perspective-based parallax on hover for depth.
- **Responsive Design** — Fully adaptive layout from desktop to mobile, with a collapsible navigation overlay on smaller screens.

## Local Development

Clone the repository and open `index.html` directly, or serve it locally:

```bash
git clone https://github.com/panwarnihal/nihal-portfolio.git
cd nihal-portfolio
npx serve .
```

No build step required. No dependencies.
